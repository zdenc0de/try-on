  3. Editar/Eliminar productos
  4. Múltiples imágenes por producto

  Fase 2: "Transaccional" (3-4 semanas)

  1. Sistema de mensajería in-app
  2. Sistema de ofertas
  3. Notificaciones (email + push)
  4. Reviews y ratings

  Fase 3: "Diferenciación IA" (4-6 semanas)

  1. "Encuentra prendas similares" (visual search)
  2. Recomendaciones personalizadas
  3. Chatbot asistente de compras
  4. Estimador de precio de mercado

  Fase 4: "Monetización" (2-3 semanas)

  1. Listings destacados
  2. Verificación de vendedor
  3. Suscripción Pro

  💡 FEATURES "WOW" PARA DESTACAR

  Estas son las que harían viral el producto:

  1. "Sube una foto de algo que te gusta → te encontramos similares"
    - Ya tienen Gemini integrado, es factible
    - Diferenciador masivo vs Vinted/Wallapop
  2. "Try-On Virtual con IA"
    - Modelos como IDM-VTON o similares
    - El nombre del proyecto es "Try-On" - sería coherente
  3. "Price Check"
    - Escaneas una prenda y te dice el precio de mercado
    - Útil tanto para compradores como vendedores
  4. "Outfit Builder con IA"
    - "Tengo estos jeans, ¿qué tops combinan?"
    - Cross-sell natural
